## Color Palette & Branding

```
Primary:   #4f46e5 (Indigo 600) - Main actions, links
Secondary: #7c3aed (Violet 600) - Secondary actions
Success:   #10b981 (Emerald 600) - Match scores, success states
Warning:   #f59e0b (Amber 500) - Alerts, warnings
Error:     #ef4444 (Red 500) - Errors, missing skills

Dark Mode Background: #111827 (Gray 900)
Light Mode Background: #f9fafb (Gray 50)
Card Background: #ffffff / #1f2937

Font: Inter (clean, professional)
Icons: Custom icon set or Heroicons
```

## Responsive Behavior

- **Desktop (1024px+)**: Full 2-column layouts, detailed views
- **Tablet (768px-1023px)**: Collapsible sidebar, condensed cards  
- **Phone (<768px)**: Single column, mobile-optimized forms

## Animation & Interactions

- **Job cards**: Hover lift effect, smooth transitions
- **Match scores**: Animated progress bar fill
- **Navigation**: Smooth page transitions
- **Forms**: Inline validation with micro-animations
- **Loading**: Skeleton screens for results

---

*This visual preview represents the complete user experience vision. All components designed for maximum usability and Dubai-specific job market targeting.*
